Рекомендовано дати новий повний обґрунтований строк з дати **фактичного** погодженого уточнення, з урахуванням локального порядку конкурсу; конкретну дату визначає Інститут.

## Межі й безпека
- Без змін: `public/vacancies/` (історичні архіви), наказ №118/к (PDF), `date`, `publicationDate`, `deadlineDate`.
- Без оприлюднення: персональні документи, бюлетені, внутрішні картки, непогоджене уточнення, незатверджені результати.
- Ніяких merge/deploy до окремого дозволу.
- Технічне підтвердження: `npm ci`, `npm run validate`, `npm audit --audit-level=low`, `git diff --check`; PR CI запускає `npm ci` та `npm run validate`. Додаткові місцеві команди треба виконати в робочій копії репозиторію; оточення цього сеансу не має прямого мережевого git-доступу до GitHub.
